Optimized Project Planning Assignment Outline (One-Sprint Focus)
================================================================

This outline structures the planning process for a tightly scoped project, starting with the big-picture context and moving directly into the single-sprint execution details.

I. Strategic Foundation (The WHY and WHO)
-----------------------------------------

This section defines the long-term direction, the target users, and the core business justification. These elements are the **most stable** over time.

1.  **Project Name / Title**

2.  **Team Members / Roles**

3.  **Product Vision**

    -   *The long-term, inspirational state (3-10+ years).*

4.  **Target Audience / Personas**

    -   *Definition and detailed profile of the primary user(s). Personas must be defined here as they inform all subsequent planning.*

5.  **Core Value Proposition**

    -   *The unique benefit your product offers to the target user (the "Why will they pay/use this?").*

II. Execution Focus and Scope (The WHAT and HOW for One Sprint)
---------------------------------------------------------------

This section focuses on the immediate deliverables, breaking down the single Epic that the team will complete within the one-sprint limit.

1.  **Primary Epic (The Core Deliverable)**

    -   *The single large body of work that will be completed within this assignment's scope (e.g., "The MVP for User Sign-up/Sign-in"). This replaces the longer-term Product Goal.*

2.  **Features**

    -   *Detailed, user-facing functionalities that belong to the Epic (e.g., "Password reset functionality," "Email verification step").*

3.  **Stories (User Stories)**

    -   *The smallest, actionable units of work, written from the persona's perspective (e.g., "As Sarah the Student, I can securely reset my password...").*
