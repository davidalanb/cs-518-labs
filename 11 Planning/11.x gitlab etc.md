### How to revert

Scenario:

* say, for example, you are on branch main without realizing it.
    - you make some changes, stage and commit
    - you go to push, and get blocked because you can't push to main
* you can undo the commit

Reverting:

* view the commit history
    - the most recent commit will be on top
```
git log
```
* revert (undo a commit)
    - the hash is the long sequence of letters and numbers
    - e.g.: d849595cbd528f5d1451b5ca5b81946889f54ed5
```
git revert <HASH>
```

Notes:

* If you want to keep the changes that you made to main, you will need to merge them into your dev branch.
* First make sure that you've checked out your dev branch.
```
git log
git checkout david-dev
```
* Then merge the changes you made in main:
```
git merge main
```
